# The scripting system of the mission editor

Soldiers of Anarchy ships a full mission editor reachable from the main menu,
and no documentation for it was ever released. This overview is derived from
the game data: the element names come from the classes in `soa.exe`, their
meaning and parameters from the text resources of the editor
(`TRES_EDITOR.trs`).

A script is made of **triggers** (the condition telling when something happens)
and **events** (what happens). The parameters reference objects placed in the
map, regions drawn in the editor or groups of units.

Generated by `_research/tools/gen_editor_docs.py`.

## Unit behaviour scripts

Ready-made behaviour patterns that can be assigned to a unit.

**Ground units:** `Animation`, `EnterLeave`, `GetReadyForInOut`, `HomeTower`, `Move`, `Patrol`, `ResumeAction`, `Rotation`, `StartEngine`

**Helicopters:** `GoingDownForCrash`, `Land`, `Land_GetOff`, `Move`, `TakeOff`, `Wait`, `WaitForEngine`

**Aeroplanes:** `Animation`
