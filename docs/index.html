What comes with the launcher

It just starts

The wrapper, the display mode, the settings, the keys on WASD. Done for you instead of read off a forum thread.

Saves you can edit

What is in a save without loading it, and what each soldier carries - the pack, the weapon, the ammunition, the vest - swapped for anything in the game.

Every item, described

The catalog, out of the game's own data: what each weapon and vehicle is, what it costs, what it is worth.

Keys, remapped

Every action the game can bind, with its two keys, in one window: click, press, done. The game's own dialog does it too - this one shows all 67 at once and marks a key bound twice.

A console, from your phone

The game's log and its cheats, drivable from a phone on the same network - because leaving full screen to type something loses the window.

The mission map

The map of what you are playing, read out of the game's memory while it runs - and a button on it that calls an air strike on the point you click.

All 1253 models

Every soldier, vehicle, building and tree the game draws, with their textures, turned under the mouse.

The game itself, made better to fight in

Beyond the wrapper and the tools, the launcher changes a handful of bytes inside soa.exe - each found by its surroundings, each with a box in the launcher's Patches window, each put back with one click. Together they give the 2002 game what it never had:

The M34 grenade

A sixth thrown weapon, item 150 - two records in Data.set, an icon, four texts, and nine places in the exe that name grenades by number. Off with one click, like the rest.

Pause and give orders

The turn-based mode the 1.0 readme promised and no patch ever shipped: the pause key stops time, not you. Select, plan, order - then let it run.

Shift moves the camera five times as fast

The game has no key for it. Hold Shift while panning, turning or zooming.

Stays open when you look away

The stock game drops to the taskbar the moment another window is clicked, full screen too. Not any more - so the console and the map can be used beside it.

No logos, no intro, straight to the menu

And the log readable while the game writes it, which is what lets the console follow it live.

A lost frame no longer ends the game

When the full screen is lost or comes back, the graphics driver can refuse one frame - and the game's own error handler used to answer that by quitting, often in the middle of loading a save. Now the frame is skipped and the next one drawn.

Central European letters

The fonts ask Windows for the East European character set, so a Czech or Polish translation keeps its diacritics on any Windows.

Any font Windows has

The game asks Windows for Tahoma by name, nine sizes of it. Two drop-downs in the launcher put another name there - Stencil, Agency FB, whatever is installed - and the shipped one puts the file back as it came.

A mailbox for tools

A few bytes the game reads once a frame and answers on its own thread - how the map window reads the mission live, and how a program can play the game.

The arsenal, in numbers

What every round of ammunition does to a soldier, to a vehicle's hit points and to its armour, the armour it has to get under, the blast radius; every weapon's range and rate of fire; every vehicle's hit points and armour. Read off the game's code and checked with the gun - an AK‑74 does 9–11 to a monk and 3–4 to a BTR‑80's armour, and nothing to its hit points until the armour is gone. Sortable, searchable, with the game's own pictures.

Things the game never told you

Found by reading the executable and checking with the gun. Each has its chapter in architecture.md.

  • How to take an enemy vehicle in one piece. Its crew are ordinary soldiers sitting inside, and a hit reaches them only when the armour left is below the round's penetrates below - then each crewman, with a chance of (that number + 100)/400. An AK-74 (4) gets through once the armour is gone, one shot in four; an RPG (500) always, and wrecks the vehicle; a Dragunov (200) reaches a Hummer's crew from the first hit and does the vehicle 3-4 points. Two crewmen dead, the Hummer standing at 39 of 50. Hurry: within three minutes the enemy AI had walked three infantrymen over and put them in. Nobody ever bails out - the get-out order is only ever given by the player, a mission script, or a Ural unloading.
  • The air strike was there all along. The game carries the MiG-23 and the MiG-29 and a whole AirStrike.cpp: a plane with bombs in the hangar puts a jet in the ring menu - but only in missions whose designer placed target markers, and none of the campaign's has any. It was tested from a console command. Now the button is in every mission, on the point clicked.
  • There is a command console, and no way to open it. Fifty typed commands with help texts - AirStrike, height-map export, path and visibility overlays, a replay system that records every tick for debugging multiplayer desyncs - and not one key, panel or argument in the shipped build brings up a line to type into. The launcher's console reaches them through the game's own dispatcher.
  • The turn-based patch that never shipped. The 1.0 readme mentions a separate download to pause and give orders. It never reached 1.1.2: the pause key opens a panel that swallows every click. It is built now, in the mission's own tick.
  • The speech test says "Hasta la vista, baby." The Sound box on the Options screen has three icons that play a sample for their slider. The speech one plays a second and a half of somebody doing Schwarzenegger. Nothing else in the game uses the file.
  • You have been shooting the developers. The pool of names a recruit can get carries the whole team - the lead programmer, the lead 3D programmer, the lead artist, five more - and the level designers drew from the same pool: Ronny Knauth stands in the enemy lines 23 times across the campaign, four times in mission 6b alone. Their names are also base cheats: type enrico(4) on the base screen and the base is set up for mission 4 the way Enrico Falk tested it, vehicles, gear and recruits included.
  • "Ha, ho, he! Hertha BSC!" A man in Bergstadt (mission 4) shouts the chant of Berlin's football club; Silver Style was a Berlin studio. The tutorial has hidden endings too: shoot your own men and the instructor throws you out, wander off and he gives you two tanks instead - "No rules. No help." - and drive the wrong way and he scolds you in German, the one line the English build never translated.
  • Dune. Four of the women's names are Reverend Mothers from Heretics of Dune - Odrade, Taraza, Schwangyu, Lucilla - and the Thumper Decoy that lures the crawler mines is the thumper that calls the worm.
  • A map of America nobody plays. The object library has a District of USA folder - three Camaros, two Dodge vans, US traffic signs, a gas station, a computer store, a Monument Valley rock, cacti - and Mission_usa.mis places 805 of them on red desert dunes with no parties at all. It loads. Nobody is there.
  • F12 takes a screenshot. Bound in the shipped settings, documented nowhere: shot0000.png and up, in the game folder. The only picture you can take of a full-screen game without leaving it.
  • The hit sounds were silent for twenty years. Five sound files whose names were written into the archive in two different encodings - the directory says one thing, the entry another - so the body hit sounds never played on any machine. Fixed with a loose file, because loose files beside the game win over the archives; that one rule is behind most of what is here.

Rather make the textures yourself?

The tools that made them are in the repository and they run against your own copy of the game, so you need not take a 316 MB download on trust:

build-package.ps1 -Variant full -Generate -Source "C:\your\game"

Under two minutes on a graphics card. It wants Python and torch, and torch is a 2.5 GB install - which is the only reason the download exists at all.

How any of this was possible

Getting the game this far meant taking a good deal of it apart, and it is all written down.

  • The 3D models. 1253 files in a format documented nowhere. They read now - with their textures, and with every part in its place, which took three wrong answers first. models.md
  • The saves. What a soldier carries is four slots inside his own record. Finding it took a false positive that looked like success for two days. saves.md
  • The engine. 538 source file names survive inside the executable, so a function can be traced back to the file its authors wrote it in. architecture.md
  • The weapons. Three damage ranges and a threshold per round, hidden in sixteen unnamed numbers; named by reading the damage code and shooting things. weapons.md
  • What did not work. As much of TODO.md records something tried that failed, and why it looked as though it had worked, as records what is still open.
